Todos conversam entre si: o mesmo login vale no backup, no domínio e nos arquivos.

Guatá ID novo · pronto

O cérebro da rede: um Active Directory completo e aberto (Samba AD DC). Login único, usuários, grupos e senhas para todos os computadores.

  • Assistente cria o domínio em ~3 minutos — você só responde perguntas simples.
  • Kerberos, LDAP e DNS prontos, sem configurar nada à mão.
  • Painel em português para criar usuários, grupos e resetar senhas.
  • Windows, Linux e o próprio guataOS entram no domínio.
sudo apt install guata-id && sudo guata-id

Guatá BackupOS pronto

A rede de segurança da empresa. Um servidor de backup dedicado, com cópias verificadas, criptografadas e à prova de ransomware.

  • Instala do pendrive como um sistema próprio — sem conhecer o motor por trás.
  • Backup de servidores, máquinas virtuais e computadores da equipe.
  • Agentes para Windows e Linux: a cópia parte do computador, criptografada.
  • Restauração simples quando o pior acontece.
Baixar ISO (servidor) 1,5 GB · BIOS + UEFI · instalável no disco

Guatá Files novo · pronto

O servidor de arquivos da empresa. Pastas compartilhadas com níveis de acesso por grupo — e a tranquilidade de voltar no tempo.

  • Níveis de acesso (tiers): Leitura, Edição e Total — por pasta, por grupo.
  • Camadas Público → Interno → Confidencial → Restrito, com grupos aninhados.
  • Entra no domínio Guatá AD (usa seus grupos) ou roda em modo simples.
  • Snapshots: "voltar no tempo" e proteção contra ransomware.
sudo apt install guata-files && sudo guata-files

Dois jeitos de instalar. Você escolhe.

O mesmo produto, do jeito que ficar melhor pra você.

1

Já tenho um Linux (jeito rápido)

Num Debian 13 ou no próprio guataOS, um comando instala tudo e abre o assistente. Perfeito para quem já tem a máquina rodando. É o modelo "um comando e pronto".

sudo apt install guata-ad
2

Quero uma máquina só pra isso (ISO)

Baixe a ISO, grave num pendrive e instale no servidor. Ele vira um aparelho dedicado: liga, o assistente aparece e cria tudo. Ideal para servidor de verdade.

Baixar ISO → gravar pendrive → ligar o servidor
